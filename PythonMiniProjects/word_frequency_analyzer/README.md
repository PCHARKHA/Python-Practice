# 📝 Word Frequency Analyzer

A command-line Python application that analyzes text by counting the frequency of each word. It allows users to search for specific words, identify the most frequently used word, and sort words based on their frequency through a simple menu-driven interface.


## Features

* Analyze user-entered text
* Count word frequencies
* Search for a specific word
* Display all word frequencies
* Find the most frequent word
* Sort words by frequency
* Menu-driven CLI interface

## Technologies Used

* Python 3
