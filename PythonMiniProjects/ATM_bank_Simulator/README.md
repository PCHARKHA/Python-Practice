# ATM Simulator (Python)

A simple console-based ATM Simulator built using Python. This project simulates basic banking operations such as account creation, login, deposits, withdrawals, money transfers, and transaction history. It was developed as a practice project to strengthen Python fundamentals.

---

## Features

* Create a new account
* Login using account number and PIN
* Account locking after 3 incorrect PIN attempts
* Check account balance
* Deposit money
* Withdraw money
* Transfer money between accounts
* Change account PIN
* View transaction history with timestamps
* Logout functionality
* Input validation using `try-except`

---

## Technologies Used
* Python 3
* `datetime` module
